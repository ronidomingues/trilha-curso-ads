# Avaliação FOrmadora 3

A pasta `AvaliacaoFormadora3`, que é fornecida pela professora, foi compactada com senha por ser conteúdo privado feito por outrem, para ter acesso a esse material, tome o link do repositório do mesmo no PDF `proposta_avaliacao_formadora_iii.pdf` e o baixe na sua máquina. Para compactar esse arquivo foi usado o comando abaixo:

```bash
    rar a -r -m5 -hp AvaliacaoFormadora3.rar AvaliacaoFormadora3/ AvaliacaoFormadora3/.*
```

E para descompactar o mesmo, use o comando:

```bash
    unrar x AvaliacaoFormadora3.rar
```

Após digitar esse comando, será necessário fornecer a senha, porém como dito antes, por questão de direitos autorais, você não a possui.

<details>
    <summary>PS.:</summary>
    A senha de descompactação é a mesma usada no usuario comum do Debian.
</details>

Caso ainda não pssua os softwares `rar` e `unrar`, instale-os, da seguinte forma:

```bash
    sudo apt update
    sudo apt install rar unrar
```
